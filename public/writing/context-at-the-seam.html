Context at the Seam

Real seated context flips a frontier model from confident abstention to correct refutation — and the whole corpus that got us there.

Correction — found, fixed, re-verified · 2026-07-24

After publishing, an adversarial audit of our own machinery found a real context-leak confound: the seated context pack pulled this experiment's own BUILDLOG, which recorded prior item-9 verdicts — so the "flip" could have been the model reading a past answer, the exact failure class this essay warns about. We removed the leak (a pack verified leak-free against every verdict pattern) and re-ran. The flip survived: item 9 still lands false_positive 3/3 with the same multi-fact synthesis on both the commodity model (gpt-4o-mini) and the frontier model (gpt-5.6-sol). Finding a confound and having the result hold clean is the strongest version of this note — and the leaking tool is being fixed so it can't recur.

The one result that changed the story

Item 9, before and after context

Item 9 (whitelist-gate-weakening, ground truth: false positive) is the hardest item in the corpus — a coherent-but-wrong narrative claim that an allowlist gate lets security exemptions propagate. Decontextualized, both models hedge. Given real seated context from the driver seam, both synthesize the multi-fact refutation and land it — every run.

Generalizes …and it holds at the commodity tier

gpt-4o-mini — roughly one-seventh the cost of the frontier models — makes the same flip: item 9 lands false_positive 3/3 with 100% schema validity and 7/9 real defects held. The context effect is not a luxury of expensive models; put the finding and the real code in front of a cheap seat and it reaches the synthesis too.

What the model actually reasoned

The refutation is a synthesis, not a lookup

The false positive claims that the health check and the secret scanner disagree, opening an exemption gap. The correct refutation requires holding two facts at once and composing them:

"The health check scans the top level only; secret_scan.py scans recursively, including subdirectories — therefore no exemption gap exists."

Neither fact is the answer on its own. That is why this item resisted decontextualized scaffolding: for a narrative-refutation finding, the minimal fair-adjudicator evidence is nearly inseparable from the refutation itself. Put the real repository context in front of the seat, and the synthesis becomes reachable — for the frontier model and the cheaper one.

Methodology · green is not correct

The seam took four tries to actually carry context

The finding above is only trustworthy because the plumbing under it is. OrchestratorDriver.decide() — the socket where the judgment model plugs in — looked green for weeks while silently failing to deliver the finding to the model. Each defect hid behind fake-backend tests that never read the prompt. Only real end-to-end runs exposed them:

  1. increment 1.5The prompt was dropped. decide() built the context prompt, then called the backend without passing it. The only thing carrying context was a test-harness side-channel no production backend implemented.
  2. increment 1.6Schema and validator disagreed. The decision schemas said one thing about evidence shape; the validator checked another. Every prior "schema-valid" was a string check. Reconciled to verdict = string enum, evidence = array, enforced.
  3. increment 1.7The evidence channel was never rendered. The prompt showed the context but not the finding-under-adjudication, so the model returned a spurious undetermined. Fixed the render, dropped a double-clip, added the assertion the fakes never had.
  4. increment 1 → 1.7The pattern itself. Four iterations, each masked by a passing suite. The corpus below is the receipt that the seat now really works — measured on real context, not on a mock that agrees with itself.

The floor is generational, not price. Every 2025–26 model refutes mechanism-checkable false claims regardless of cost tier; total rubber-stamping only appears in the 2024 gpt-4o class. Narrative refusal is frontier-exclusive: refuting a coherent-but-wrong story runs from 80% (Opus) down to 0% (gpt-4o). That residue — items like #9 — is exactly what seated context reaches into.

Caveat that keeps the ladder honest: Anthropic rungs run through harness subagents that inherit the repo's own audit culture and memory, so their verdicts aren't cleanly isolatable from that prior. OpenAI rungs go through the seam with captured receipts. The two columns aren't strictly comparable — read the split, not the leaderboard.

What this is not

A bounded result, stated as one. The A/B is N=3 on a single item across three OpenAI-seam models (gpt-5.6-sol, gpt-5.5, gpt-4o-mini) — one decision each, not a running wave. An earlier draw that flipped on a leaky corpus (the evidence stated the conclusion) was discarded; this is the neutral-corpus version. A gpt-4o run was rate-limited and excluded rather than reported as data; gpt-5.6-luna and -terra remain to run. The ladder is single-run, 16 items, no repeated-variance measurement. None of it is a benchmark authority. It is a receipt that the seat carries context, and a signal about where narrative refusal lives.
